# Архитектура «Селфи-квиз»

## Суть проекта

Веб-квиз (один HTML-файл, vanilla JS), где пользователь отвечает на вопросы
**перед селфи-камерой в реальном времени**. В момент ответа кадр замораживается,
модель сегментации отделяет человека от фона, и на стоп-кадр накладываются
яркие игровые эффекты в стиле японских шоу: неоновая окантовка силуэта, лучи
за головой, конфетти, искры, слэм-тексты.

Продуктовая цель — виральный «глупый» формат для соцсетей: результат легко
сохранить и расшарить, каждый раунд уникален (случайный фон, случайные эффекты).

## Технологии

- **Чистый HTML/CSS/JS**, без фреймворков и сборки — один `index.html`
- **Canvas 2D API** — весь рендер эффектов
- **MediaPipe Tasks Vision (`ImageSegmenter`)** — сегментация человека, WASM-модель хостится локально (без CDN)
- **Web Share API** (`navigator.share` + `navigator.canShare`) — шаринг фото; фолбэк — `<a download>`
- **getUserMedia** (`facingMode: 'user'`) — фронтальная камера

## Слои рендера

### DOM (z-index)

| z | элемент | роль |
|---|---------|------|
| 0 | `<video id="cam">` | живая камера (mirror через `transform: scaleX(-1)`) |
| 1 | `<canvas id="fx">` | все эффекты |
| 2 | `#ui` | HUD: прогресс, счёт, карточка вопроса |
| 3 | `#winOverlay` / `#loseOverlay` | вспышки «правильно/мимо» |
| 4-5 | `#startScreen` / `#endScreen` | экраны старта и финала |
| 6 | `#camOff` | кнопка выключения камеры |
| 8 | `#segError` | сообщение об ошибке сегментации |
| 9 | `#aiStatus` | индикатор статуса модели («AI: готово ✓») |

### Canvas `#fx` (порядок отрисовки в `animateFx`)

1. `bgLayer` — яркий игровой фон (случайный из 8: неон, огонь, космос, кибер, закат, радуга, океан, ретро-сетка)
2. лучи за головой (только freeze) — вращающиеся секторы с внутренним радиусом `r0=110px`, **под** человеком
3. `personLayer` — стоп-кадр человека, вырезанный маской (`destination-in`)
4. `glowLayer` — тройная окантовка: внешний glow 52px + средний 20px + белая кромка 6px (пульс 0.8±0.2)
5. частицы: конфетти (freeze) / дождь (rain)
6. искры-звёзды (freeze), слэм-тексты («СУПЕР!», «ОГО!» с easeOutBack-масштабом)
7. вспышка экрана (`flash`, затухает `*0.85/кадр`) + случайные грозовые вспышки (rain)

Пока маска не готова — рисуется `snapshot` (обычный стоп-кадр), затем слои «проявляются».

## Сегментация (MediaPipe Tasks)

```
initSelfieSeg()
  ├─ import('/quiz/vendor/tasks/vision_bundle.mjs')
  ├─ FilesetResolver.forVisionTasks('/quiz/vendor/tasks/wasm/')
  └─ ImageSegmenter.createFromOptions({ modelAssetPath: '.../selfie_segmenter.tflite',
                                        runningMode: 'IMAGE', outputCategoryMask: true })

makeMask()  — вызывается при каждом ответе
  ├─ canvas-кадр из текущего видео (video-элемент в segment() нестабилен → рисуем в canvas)
  ├─ segmenter.segment(canvas)
  ├─ categoryMask.getAsUint8Array()
  ├─ ⚠️ ИНВЕРСИЯ: модель отдаёт 255=ФОН, 0=человек → alpha = 255 - value
  ├─ собрать RGBA-маску (альфа = человек, фон прозрачен)
  └─ resolve({ mask, error })  — общий дедлайн 20с (модель + сегментация)
```

Ключевые решения:
- **Никакого тихого фолбэка**: если маска не пришла за 20с / модель недоступна — показывается `#segError` (без подмены обычным стоп-кадром «молча»).
- **Инверсия маски** — критический нюанс: `destination-in`/`destination-out` работают по альфа-каналу. Ошибка здесь давала «вырезание фона» вместо человека (долго ловился на проде).
- **Дедлайн 20с** — покрывает и ожидание загрузки модели (poll каждые 200мс), и саму сегментацию.

## Эффекты: freeze vs rain

| | freeze (правильно / победа) | rain (мимо / поражение) |
|---|------------------------------|--------------------------|
| фон | случайный яркий | случайный яркий |
| контур | золотой `#ffd93d` | голубой `#6ea8ff` |
| лучи за головой | ✅ вращаются | — |
| конфетти | ✅ 160 шт | — |
| искры-звёзды | ✅ 42 шт от головы | — |
| слэм-тексты | «СУПЕР!», «ОГО!», «КАВАЙИ!»… | «ОЙ-ОЙ!», «УПС!», «Zannen…» |
| вспышка | золотая | синяя + случайные грозовые |

## Данные и состояние

```
score, qIndex, locked        — логика игры

snapshot                     — замороженный кадр (offscreen canvas)

```

## Шаринг и лента

- `captureRoundShot()` — после каждого ответа (в `nextBtn.onclick`) собирает статичный кадр (фон+человек+контур, JPEG 0.85) в `roundShots[]`
- `finish()` → `renderRoundStrip()` — горизонтальная прокручиваемая лента миниатюр; тап по фото = скачивание
- `buildShareImage()` — финальный кадр + счёт («🏆 5/6») и подпись; `shareBtn` → `navigator.share({files})`, фолбэк — скачивание

## Подводные камни (проверено на проде)

1. **Маска инвертирована** (255 = фон) — обязательно `alpha = 255 - v`.
2. **`segment(video)` нестабилен** — передавать canvas-кадр.
3. **`destination-in` по альфе** — чёрные пиксели с alpha=255 «не вырезаются»; фон маски должен быть прозрачным.
4. **Лучи поверх человека** заливали лицо (24 треугольника сходились в центре) — рисовать под personLayer + внутренний радиус.
5. **nginx MIME**: `.mjs` обязан быть `application/javascript` (добавить в `/etc/nginx/mime.types`), иначе ES-module не загрузится.
6. **Secure context** — камера и Web Share работают только по https.
7. **Deduplicate слоёв** — слои строятся один раз на ответ, не в rAF (иначе лаги на мобильных).
